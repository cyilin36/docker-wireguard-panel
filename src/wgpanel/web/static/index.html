客户端（Peer）

每个「客户端」就是一台要连进来的设备（手机、笔记本、路由器）。 下行＝服务器发给它的速度，上行＝它发给服务器的速度； 在线＝最近 3 分钟内有过握手。鼠标停在表头上有每条的含义。

名称 隧道地址 状态 对端地址 下行 上行 累计流量
